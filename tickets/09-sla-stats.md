# DSP-9. Сроки, статистика и скорость

**Автор:** Марина Кольцова, тимлид · **Неделя:** 9

Жилищная инспекция спрашивает с управляющей компании сроки [А3, Б3], директор — кто работает лучше [А6]. Отвечаем командой `stats`. И вспоминаем НФ из ТЗ: три года заявок — это около 150 000, а в пиковый год и все полмиллиона. Программа должна считать статистику по такому файлу быстро.

## Что сделать

### 1. Сроки — `include/dispatch/sla.hpp`

```cpp
namespace dispatch {
// Срок выполнения заявки, созданной в created (ГГГГ-ММ-ДД ЧЧ:ММ):
//   аварийная — через 1 час, обычная — через 24 часа,
//   плановая — через 5 рабочих дней в то же время суток.
std::string deadline(const std::string& created, const std::string& priority);

long long minutes_between(const std::string& from, const std::string& to);   // to − from, в минутах

// Выполнена позже срока. Невыполненная (пустое done) — false.
bool overdue(const Request& r);
}
```

Рабочий день — понедельник–пятница (праздники заказчик пришлёт позже — это открытый вопрос в ТЗ). Плановая заявка, созданная в пятницу в 10:00, должна быть выполнена к пятнице следующей недели в 10:00; созданная в субботу — тоже к пятнице.

Даты — через календарь `std::chrono` из C++20: `std::chrono::year_month_day`, `std::chrono::sys_days` (число дней), `std::chrono::weekday`. Своя арифметика дат «вручную» (сколько дней в феврале) — источник ошибок; не пишите её.

### 2. `dispatch stats ФАЙЛ`

По выполненным заявкам (состояние `выполнена` или `закрыта`):

```text
$ dispatch stats checks/rep4/data/month.csv
Вид работ     выполнено  просрочено  в срок, %  среднее
сантехника          107          17       84.1    44:49
электрика            55          13       76.4    44:27
лифт                 24           5       79.2    42:45
отопление            61          10       83.6    35:39
уборка               34           5       85.3    50:16
прочее               20           1       95.0    43:30
всего               301          51       83.1    43:15

Лучшие мастера:
  1. Фёдоров — 75
  2. Васильев — 62
  3. Петров — 23
```

- Столбцы — как в `report` (DSP-4): первый — 12 символов, остальные — ширина заголовка плюс 2, по правому краю.
- `в срок, %` — доля выполненных не позже срока, одна цифра после запятой; если выполненных нет — `—`.
- `среднее` — среднее время от создания до выполнения, целых минут (дробную часть отбросить), в виде `Ч:ММ` — часов может быть сколько угодно.
- «Лучшие мастера» — до трёх по числу выполненных заявок, при равенстве — по фамилии (сравнение строк `<`). Выполненных нет — строки «Лучшие мастера» и пустой строки перед ней нет.

### 3. Скорость

`dispatch stats` по файлу из 500 000 заявок (сборка Release без санитайзеров) — не дольше **3 секунд**. Проверка сама сгенерирует такой файл (`checks/gen_requests.py 500000`) и засечёт время. Правильное решение укладывается в полсекунды. Если не укладываетесь — ищите квадратичное: поиск повтора номера при загрузке, поиск в векторе внутри цикла, пересчёт одного и того же.
