### 2. Файл заявок и `dispatch count`

Заказчик хочет открывать файл в Excel [Б7], поэтому храним заявки в CSV: UTF-8, разделитель `;`, первая строка — заголовок, дальше по заявке в строке:

```text
номер;создана;дом;подъезд;квартира;телефон;вид;срочность;состояние;мастер;выполнена;описание
17;2026-10-05 08:15;Лесная 12;2;45;+79161234567;сантехника;аварийная;выполнена;Петров;2026-10-05 09:02;Течёт стояк; вода в подъезде
```

| Поле | Что это |
|---|---|
| номер | целое больше нуля |
| создана, выполнена | `ГГГГ-ММ-ДД ЧЧ:ММ`; «выполнена» пустое, пока заявка не выполнена |
| дом | улица и номер дома одной строкой |
| подъезд, квартира | целые |
| вид | `сантехника`, `электрика`, `лифт`, `отопление`, `уборка`, `прочее` |
| срочность | `аварийная`, `обычная`, `плановая` |
| состояние | `новая`, `назначена`, `выполнена`, `закрыта`, `отменена` |
| мастер | фамилия или пусто |
| описание | всё до конца строки — **может содержать `;`**: полей в строке 12, а разделителей бывает больше |

Первая команда программы — сводка по видам работ:

```text
$ dispatch count data/requests.csv
сантехника: 5
электрика: 3
лифт: 0
отопление: 2
уборка: 1
прочее: 0
всего: 11
```

- Виды — всегда все шесть, в этом порядке, даже с нулём.
- Строка, в которой меньше 12 полей, или с неизвестным видом работ — не считается; в **stderr** сообщение с номером строки файла (заголовок — строка 1): `строка 7: полей 5, нужно 12`, `строка 9: неизвестный вид работ «газ»`. Пустые строки (и строки из одних пробелов) пропускаются молча.
- Файл, сохранённый из Excel, начинается с метки порядка байтов UTF-8 (BOM, байты `EF BB BF`) и имеет переводы строк Windows (`\r\n`). Такой файл должен читаться так же, как обычный.
- Первая строка (без BOM и `\r`) — не заголовок из примера выше → в stderr `не файл заявок: первая строка — не заголовок`, код возврата 1.
- Файл не открывается → `не открыть файл: <путь>`, код 1. `dispatch count` без файла → справка по использованию в stderr, код 2.
- Справка `dispatch --help` упоминает команду `count`.

Пока всё может жить в `src/main.cpp`; в DSP-5 разнесём по модулям. Файл читайте `std::ifstream` и `std::getline`, поля — поиском `;` (`std::string::find`, `substr`) или `std::getline(поток, поле, ';')`.
